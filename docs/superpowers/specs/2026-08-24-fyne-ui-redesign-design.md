# GitHub 文章发布器 · Fyne UI 视觉重设计

## 背景

用户提供了一份来自 Claude Design 的 handoff 设计稿（`Fyne UI 设计方案-handoff.zip`），主题名为「github代码(文件) 2.35 · Fyne 界面重设计」。经完整阅读设计稿的 HTML/CSS 与内嵌 JS 状态逻辑，确认设计稿编码的业务是批量非本人 GitHub 账号 Cookie（CK）群发、配合代理池规避风控、打码平台绕过验证码、伪原创内容模板、第三方"蜘蛛"服务强制搜索引擎收录——属于黑帽 SEO 群发/站群工具，不予实现（含纯 UI 壳）。

与用户确认后，采纳方案：**只移植设计稿的视觉风格（配色、字体、圆角卡片、深浅主题、终端日志面板、状态徽标等视觉语言），套用到本项目现有的合规功能上**——即"用个人 GitHub Access Token，把本地 Markdown 文章发布到自己仓库"的单账号发布器。不新增、不实现设计稿中的账号池、代理、打码、蜘蛛提交、内容伪原创、采集文章等功能。

## 现状

`internal/ui/mainwindow.go` 用 Fyne 默认主题、单页 `container.NewBorder` 布局：顶部设置表单 + 文件队列工具条，中间 `widget.Table` 展示队列（文件名/仓库路径/状态），底部开始/停止/导出按钮 + 纯文本日志框。业务逻辑（`internal/config`、`internal/github`、`internal/publisher`、`internal/article`）不受本次改动影响。

## 目标

重写 UI 层，视觉上对齐设计稿的风格系统，同时保持现有全部功能行为不变（新增极少量纯展示型小功能：日志复制/导出、帮助页）。

## 设计

### 1. 窗口外壳与布局

```
┌─────────────────────────────────────────────────────────┐
│ 标题栏: [G]徽标 GitHub 文章发布器  状态胶囊         ☀/🌙   │ 52px
├──────────┬──────────────────────────────┬────────────────┤
│ 左侧导航  │ 内容区（当前选中页）              │ 右侧参数栏      │
│ ·发布    │                                │                │
│ ·帮助    │                                │                │
│  182px   │                                │  264px         │
├──────────┴──────────────────────────────┴────────────────┤
│ 终端风格日志面板 RUNTIME LOG                                │ 224px
├─────────────────────────────────────────────────────────┤
│ 底部状态栏: 总数 / 成功 / 失败 / 待发 / 已用时                │ 36px
└─────────────────────────────────────────────────────────┘
```

窗口默认尺寸 1120×760，可自由缩放（不采用设计稿画布用的 1440×900 作为固定/最小尺寸）。

左侧导航仅两项：**发布**（现有核心功能）、**帮助**（README 使用说明的卡片化展示）。不做设计稿中的内容设置/IP设置/打码设置/蜘蛛设置/其他设置/采集文章。

### 2. 主题与视觉规范

新增 `internal/ui/theme.go`，实现 `fyne.Theme` 接口（`Color`/`Font`/`Size`），Light/Dark 两套配色取自设计稿自带的对照表：

| 用途 | Light | Dark |
|---|---|---|
| 主面板背景 | #FFFFFF | #161B22 |
| 导航/标题栏/状态栏背景 | #F3F5F7 | #11161D |
| 输入框/表头背景 | #F6F7F9 | #1B2129 |
| 正文文字 | #1A1E23 | #E6EDF3 |
| 次要文字 | #6E7681 | #8B949E |
| 描边 | #B6BDC7 | #3D444D |
| 分割线 | #DCE0E6 | #2A313A |
| 主色（按钮/选中态） | #1F6FEB | #388BFD |
| 选中底色 | #E7F0FE | #132A4D |
| 成功 | #1A7F37 | #3FB950 |
| 警告 | #9A6700 | #D29922 |
| 失败 | #CF222E | #F85149 |
| 日志面板背景 | #0B0E12 | #05070A（深浅主题下日志面板均为深底） |

- 主题启动时跟随系统（`fyne.CurrentApp().Settings().ThemeVariant()`），标题栏图标按钮可手动切换，选择记忆到 `fyne.Preferences`。
- 圆角：卡片/按钮 6–10px，使用 `canvas.Rectangle.CornerRadius`（Fyne 2.8 已支持，无需降级处理）。
- 字体：中文正文用系统默认中文回退（先用 Fyne 2.8 自带 CJK 支持验证效果），等宽场景（日志、数字、路径、Token 状态）尽量选用等宽渲染；若 Windows 下实测中文缺字或等宽效果不达标，再决定是否内嵌字体资源，避免不必要地把大字体文件打进单文件可执行程序。

### 3. 发布页（唯一功能页，逻辑不变）

- 顶部工具条：`选择文件夹` `添加文件` `清空`，按钮样式改为设计稿的圆角胶囊风格，功能不变。
- 设置区改为卡片+浮动小标签样式（参照设计稿"分组框"视觉），字段不变：Token（带验证按钮和状态文字）、Owner、Repo、分支、目标目录、发布间隔（秒）、失败重试次数、自动创建仓库勾选框。
- 文件队列表格套用设计稿账号列表的视觉：灰底表头、状态列用彩色圆角徽标组件（待发布=灰、发布中=黄、成功=绿、失败=红），行 hover 高亮。表格列不变：文件名 / 仓库路径 / 状态。

### 4. 帮助页（新增）

内容来自现有 `README.md`（Token 权限要求、支持文件格式、发布行为说明、配置保存位置），用设计稿"使用说明"页的卡片列表样式静态展示。不含设计稿里的外部工具/补丁链接卡片。

### 5. 状态胶囊 / 右侧参数栏 / 日志面板 / 底部状态栏

- **状态胶囊**（标题栏右侧，带脉冲小圆点动画）三态：`待机` / `发布中 · N/M` / `已完成`（若有失败显示 `N 成功 · M 失败`）。不做"暂停"态——现有 `publisher.Run` 只支持顺序发布 + `context` 取消，不新增暂停能力。
- **右侧参数栏**：只读展示当前"发布间隔 / 失败重试 / 队列篇数"，下方是开始/停止大按钮（待机态蓝色"开始发布"，运行中红色"停止"，与设置区按钮联动同一逻辑，非重复实现），再下方"保存配置 / 清空队列 / 导出链接"三个快捷按钮（复用现有对应逻辑）。
- **日志面板**：深底、等宽字体、按事件类型着色（成功绿/失败红/重试黄/信息灰），顶部工具条新增"自动滚动开关 / 复制到剪贴板 / 导出为 txt / 清空"。复制和导出为新增的小功能（工作量小，直接实现，不设开关跳过）。
- **底部状态栏**：总数 / 成功 / 失败 / 待发 / 已用时，数据来自现有 `RowState` 统计 + 新增一个发布耗时计时（开始发布时起计时，完成/停止时定格）。

### 6. 明确不做

不实现设计稿中的：CK 账号池、代理 IP 设置、打码平台、蜘蛛提交、内容伪原创模板/标签变量、采集文章、多账号轮换、外链轮链、授权到期字段。左侧导航固定两项（发布、帮助），不做可扩展的动态页签系统。

### 7. 代码改动范围

只改 `internal/ui/`（重写 `mainwindow.go`；新增 `theme.go`、状态徽标组件、帮助页视图、状态胶囊组件）和 `main.go`（应用自定义主题）。`internal/config`、`internal/github`、`internal/publisher`、`internal/article` 业务逻辑包不变，其现有单元测试保持通过。

## 测试

- `internal/ui` 目前有 `state_test.go`，覆盖 `RowState` 逻辑，本次改动不涉及该逻辑，测试应继续通过。
- UI 层其余部分是 Fyne 组件装配，以手动运行验证为主（`go run .` 检查发布页/帮助页/主题切换/日志面板在 Light 和 Dark 下的显示效果）。
- 不新增 mock/集成测试基础设施，保持与现有项目的测试范围一致。
